# ⚡ DataPilot — Next-Gen AI Data Analytics & Storytelling

An advanced, aesthetic Streamlit chat application for instant data analytics, automated chart generation, data hygiene auditing, and 1-click executive PowerPoint presentation generation.

## 🚀 Features
- **100% Free & Local:** Powered by deterministic Pandas calculations with zero paid API keys needed.
- **Natural Language Chat:** Ask questions about averages, totals, distributions, and grouped analytics in plain English.
- **Aesthetic Chart Studio:** Custom dark-mode visuals (Bar, Line, Scatter, Histogram, Box).
- **Data Quality Radar:** Detect missing records, duplicate rows, and schema types.
- **1-Click PowerPoint Deck:** Auto-synthesize insights and export a 6-slide `.pptx` deck.
- **CSV & Excel Support:** Seamlessly load `.csv`, `.xlsx`, or `.xls` datasets.

## 🛠️ Quickstart

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Run the App
```bash
streamlit run app.py
```
